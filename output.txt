## What was created

config.py (148 lines)
  - Config frozen dataclass with all project constants
  - load() function that reads .env and environment variables
  - __main__ block for direct testing

.env.example
  - Documents every environment variable
  - REQUIRED / OPTIONAL tags on each entry
  - Placeholder values and one-line descriptions

requirements.txt
  - python-dotenv==1.0.1 only (grows with each build step)


## How to test it

1. Install the dependency:
   pip install -r requirements.txt

2. Create your .env file:
   cp .env.example .env

3. Edit .env and fill in the four required keys.
   Placeholder strings work for this step — they just need to be non-empty:
   DEEPGRAM_API_KEY=test_key
   TTS_API_KEY=test_key
   TTS_VOICE_ID=test_voice
   LLM_API_KEY=test_key

4. Run the pass condition:
   python config.py

## What fails and why if a required variable is missing

If any of these four variables is absent or empty in .env:
  DEEPGRAM_API_KEY
  TTS_API_KEY
  TTS_VOICE_ID
  LLM_API_KEY

load() raises immediately with a clear message, e.g.:

  ValueError: Required environment variable 'DEEPGRAM_API_KEY' is missing or empty.
  Copy .env.example to .env and fill in all required values.

The error names the exact missing variable. All other variables have defaults
defined in the Config dataclass and will never raise.
